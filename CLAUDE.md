# CLAUDE.md

Guidance for Claude Code in the Al Ummah Now www site (Astro). See `README.md` for setup and commands.

## UI copy

- **Tone (en + ar)**: Al Ummah Now is a content-sharing site, not a lectures library. Describe it the way YouTube's interface does: videos, Shorts, live streams, posts, playlists, channels, creators, viewers, the community; verbs watch, upload, share, subscribe (never "follow" a channel), save, explore. Never describe the platform as lessons, lectures, courses, a library, "beneficial knowledge" or "keep learning" («دروس، محاضرات، مكتبة، العلم النافع، واصل التعلّم»), and no entertainment or hype words either. A creator's own titles and content categories keep their words. Keep "Islamic" factual. Full rules with examples: wiki page "Copy Tone Guide".
- **Arabic word for "video"**: «مرئي / مرئيات», never «فيديو» or «مقاطع» for videos; «المقاطع القصيرة» stays for Shorts. See the wiki page "Arabic glossary".
- Every string lives in `src/i18n/en.ts` and `src/i18n/ar.ts` (same keys). Texts that editors manage (hero, tagline, About, list intros) live in the CMS; `src/content/fallback/` holds the copy shown when the CMS is unreachable and must match it.
- **Numbers in Arabic**: Arabic pages show Eastern Arabic (Hindi) numerals ٠–٩ in every formatted value (numbers, counts, dates, times, durations, percentages, money); English shows Arabic numerals 0–9. Format only through `packages/render/src/format.ts` (explicit `ar-u-nu-arab`, so the Worker and WebKit agree) and `fmt(template, vars, locale)`; never call `Intl.*` / `toLocale*String` elsewhere, never write `ar-SA` / `ar-EG` / `nu-latn`, and never hard-code a number in a string (use a placeholder). Ids, URLs, slugs and codes stay as typed; inputs accept ٠–٩ (`toAsciiDigits`). `apps/www/tests/format-guard.test.ts` enforces this.
- **Arabic number rule (owner, 2026-11-21)**: Arabic numbers are never grouped, «٫» is the only mark (`formatNumber` drops grouping in Arabic whatever the options). Counts (views, likes, comments, results) from 1,000 on go through `formatCompact` (or `formatCountNoun(…, { compact: true })`): cut, never rounded, «٤٫٨ ألف» / "4.8K", millions always «م», billions «مليار», a standalone whole 11–99 in the accusative («٢٥ ألفًا»). Tables, money and sizes stay exact. Arabic meta lines join with «،» (`joinMeta` / `metaSeparator`, or the `:lang(ar)` CSS), never «•» or «·». `apps/www/tests/number-rule.test.ts` and the «٬» guard in format-guard enforce it.
