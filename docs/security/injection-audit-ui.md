# Injection Security Audit — AlUmmahNowUI

Defensive injection audit across `packages/render`, `apps/www`, and `apps/sites` covering Markdown/rich-text rendering, community posts and CMS page-builder blocks, every Astro `set:html` and client `innerHTML` sink, JSON-LD/meta escaping, RSS/sitemap XML escaping, open redirects, CRLF/header injection, log injection, and CSP.

## Findings & Control Inventory

| Component | Input | Risk | Fixed / OK | Test |
| --- | --- | --- | --- | --- |
| Markdown link & image renderer (`packages/render/src/markdown.ts`, `packages/render/src/urls.ts`) | CMS page/post Markdown, scholar site About/page Markdown | **High (UI-1 — Unsafe link/image schemes):** `markdown-it`'s default `validateLink` allowed `data:image/*`, `tel:`, `ftp:`, `blob:`, `//evil.example`, `/\evil.example`, and `mailto:` inside `<img src>`. | **Fixed:** Added strict `safeMarkdownHref()` (`http:`, `https:`, `mailto:`, safe relative `/...`, `#...` only; no control chars/backslashes) wired into `md.validateLink`, and `safeMarkdownImgSrc()` (`http:`, `https:`, safe relative `/...` only; no `data:`, `mailto:`, `javascript:`) enforced in `md.renderer.rules.image`. | `apps/www/tests/injection-audit.test.ts` (`UI-1`), `apps/www/tests/markdown.test.ts` |
| Community post channel links (`packages/render/src/posts/PostKindBody.astro`, `PostKindSummary.astro`, `PostEngagement.astro`, `post-kinds.ts`) | `post.ref.videos_url`, `postRef.videos_url`, external link URLs | **High (UI-2 — Stored XSS via `href`):** `videos_url` was passed straight into `<a href={...}>` without scheme validation; `safeOutsideUrl()` did not reject ASCII control chars before `new URL()`. | **Fixed:** Validated `videos_url` with `safeOutsideUrl()` in all three components before rendering links; rejected ASCII control chars in `safeOutsideUrl()`. | `apps/www/tests/injection-audit.test.ts` (`UI-2 & UI-3`) |
| Preview edit link, `<picture>` fallback `src`, site logos/favicons, & client DOM/URL sinks (`apps/www/src/lib/preview.ts`, `PreviewBanner.astro`, `picture.ts`, `scripts/site.ts`, `scripts/timeline-media.ts`, `scripts/facade.ts`, `apps/sites/src/layouts/SiteLayout.astro`, `SiteHeader.astro`, `pages/[locale]/about.astro`) | `preview.edit_url`, `MediaRef.url`, `logoUrl`/`faviconUrl`/`avatarUrl`, `PlayInfo` (`mp4.url`, `poster`, `watchUrl`), `data-embed-src`, mute button label | **High (UI-3 — Stored/DOM XSS via unvalidated `href`/`src` & `innerHTML`):** `edit_url`, `MediaRef.url`, site `logo`/`favicon`, client `avatarUrl`, `poster`, `watchUrl`, and `embedSrc` lacked strict URL scheme checks; `timeline-media.ts` interpolated button text into `btn.innerHTML`. | **Fixed:** Enforced `safeHttpUrl` / `safeHttpsUrl` / `safeRelativeOrHttpUrl` / `safeRelativeOrHttpsUrl` at every sink; replaced `btn.innerHTML` text interpolation with `document.createElement('span')` + `.textContent`. | `apps/www/tests/injection-audit.test.ts` (`UI-2 & UI-3`), `apps/sites/tests/injection-audit.test.ts` |
| Redirects & navigation URLs (`apps/sites/src/lib/edge.ts`, `apps/sites/src/lib/site.ts`, `apps/www/src/lib/context.ts`, `apps/sites/src/components/SiteBlocks.astro`, `apps/www/src/lib/auth-routes.ts`, `apps/sites/src/lib/auth-routes.ts`) | Site `redirects[].to`, registry `redirectTo`, CMS `nav_items.url`, block CTA `href`, auth callback `returnTo`, logout `?next=` | **Medium (UI-4 — Open redirect & backslash/CRLF bypass):** `/^\/(?!\/)/` matched `/\evil.example` and control chars; auth callbacks did not re-validate `returnTo`; logout `?next=` and registry `redirectTo` did not reject control chars. | **Fixed:** Enforced `safeRelativeOrHttpsUrl` / `isSafeRelativePath` / `safeHttpUrl` (rejecting `\`, `//`, whitespace, and control chars); re-validated `safeReturnPath()` on both `www` and `sites` auth callbacks; rejected control chars in logout `?next=`. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`), `apps/sites/tests/injection-audit.test.ts` |
| JSON-LD script serialization (`apps/www/src/lib/seo.ts`, `apps/sites/src/lib/seo.ts`, `packages/render/src/urls.ts`) | Structured data serialized into `<script type="application/ld+json">` | **Medium (UI-5 — Incomplete JSON-LD escaping):** `jsonLdText` escaped only `<`, leaving `>`, `&`, U+2028, and U+2029 unescaped. | **Fixed:** Replaced both `jsonLdText` implementations with shared `safeJsonLd()` escaping `<`, `>`, `&`, U+2028, and U+2029 (`\u003c`, `\u003e`, `\u0026`, `\u2028`, `\u2029`). | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`), `apps/sites/tests/injection-audit.test.ts` |
| Image URL helper (`packages/render/src/images.ts`) | `stableImageUrl()` input (OG image, JSON-LD, search suggestions) | **Medium (UI-6 — Unvalidated scheme passthrough):** Unsigned URLs were returned verbatim even when using `javascript:` or `data:` schemes. | **Fixed:** Validated unsigned URLs with `safeRelativeOrHttpUrl()`, returning `null` for disallowed schemes or control chars. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`) |
| Outbound newsletter header forwarding (`apps/www/src/lib/newsletter.ts`) | `CF-Connecting-IP` forwarded as `X-Client-IP` | **Medium (UI-7 — Header / CRLF injection):** Forwarded `ip` header value without character/length validation. | **Fixed:** Validated `ip` against `/^[0-9a-fA-F:., ]{1,64}$/` before setting `X-Client-IP`. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`) |
| Structured error logs (`packages/render/src/urls.ts`, `profile-name.ts`, `apps/www/src/worker.ts`, `pages/500.astro`, `lib/auth-routes.ts`, `lib/newsletter.ts`, `apps/sites/src/lib/site.ts`, `lib/data.ts`) | Caught error messages | **Low/Medium (UI-8 — Log injection):** `String(error)` could contain CR/LF/control chars and unbounded length. | **Fixed:** Added `sanitizeLogError()` stripping `[\r\n\u0000-\u001f\u007f]` and capping length at 500 chars across `www`, `sites`, and `packages/render`. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`) |
| External links & search suggestions (`apps/www/src/components/Footer.astro`, `apps/www/src/lib/search/suggest.ts`, `apps/sites/src/components/SiteHeader.astro`, `PostCard.astro`, `pages/[locale]/about.astro`, `lib/seo.ts`) | Social links, channel links, article links, search hit `href` & `thumbnailUrl` | **Low/Medium (UI-9 — Loose regex URL checks):** `/^https:\/\//` allowed spaces/control chars; `isSafeHref` did not explicitly reject ASCII control chars. | **Fixed:** Replaced loose regexes with `safeHttpsUrl()` and added explicit control-char rejection in `isSafeHref()`. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`), `apps/sites/tests/injection-audit.test.ts` |
| CSP & security headers (`apps/www/src/lib/edge.ts`, `apps/sites/src/lib/edge.ts`) | All HTML and asset responses on `www` and scholar sites | XSS, clickjacking, MIME sniffing, base-tag hijack | **OK:** Strict CSP on all `text/html` (`default-src 'self'`, hash-pinned `script-src` with no `unsafe-inline`/`unsafe-eval`, `style-src 'self'`, `object-src 'none'`, `frame-ancestors 'none'` / preview embed origin only, `base-uri 'self'`, `form-action` pinned to self + auth, `upgrade-insecure-requests`), plus `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `HSTS`, `COOP`, `Permissions-Policy`. | `apps/www/tests/injection-audit.test.ts` (`UI-4..UI-10`), `apps/sites/tests/injection-audit.test.ts` |
| Astro `set:html` sinks (`BaseLayout.astro`, `SiteLayout.astro`, `Header.astro`, `SiteHeader.astro`, `Blocks.astro`, `SiteBlocks.astro`, `PageArticle.astro`, `PostArticle.astro`, `FeedCard.astro`, `CardGrid.astro`, `CardViewer.astro`, `about.astro`, `[slug].astro`, `scholars/*`) | Rendered Markdown, page blocks, `<picture>`, video facades, shared nav HTML, `MODE_SCRIPT`, JSON-LD | Stored XSS | **OK:** Every `set:html` sink receives only static constants (`MODE_SCRIPT`, icons), `safeJsonLd()`, `renderMarkdown()` (`html: false` + strict URL allowlists), `renderPageBlocks()` (escaped structured blocks, no raw HTML/CSS), `pictureHtml()` (escaped + scheme-validated), `facadeHtml()` (escaped + `VIDEO_ID`-validated), or `fanous-nav` escaped builders. | `apps/www/tests/markdown.test.ts`, `apps/www/tests/injection-audit.test.ts`, `apps/sites/tests/injection-audit.test.ts` |
| RSS & Sitemap XML generation (`apps/www/src/pages/[locale]/rss.xml.ts`, `scholars/[slug]/rss.xml.ts`, `apps/www/src/lib/sitemap.ts`, `apps/sites/src/lib/sitemap.ts`) | Titles, excerpts, slugs, scholar names, URLs | XML / RSS injection | **OK:** All dynamic XML text and attributes are escaped via `escapeHtml` (`&`, `<`, `>`, `"`, `'`), slugs are `encodeURIComponent`-encoded or regex-validated, and `lastmod` dates are validated ISO/UTC strings. | Existing sitemap/RSS tests + code inspection |
| Client-side DOM scripts (`apps/www/src/scripts/cards.ts`, `timeline.ts`, `search-combobox.ts`, `apps/sites/src/scripts/site.ts`) | Search hits, recent queries, card lightbox, account menu, timeline "Load more" | DOM XSS | **OK:** `cards.ts` uses static SVG markup in `dlg.innerHTML` and `.textContent`/`.setAttribute` for text; `search-combobox.ts` and `sites/scripts/site.ts` build DOM nodes with `.textContent` only; `timeline.ts` fetches same-origin server-rendered HTML only. | Code inspection + `apps/www/tests/injection-audit.test.ts` |
